# koishi-plugin-febfrost-arknights-info

明日方舟干员信息推送插件。首版聚焦干员生日：每日凌晨向白名单群聊推送今日生日干员，周一推送本周每天生日干员，也支持命令手动查询。

- `今日生日干员` / `今日干员`：发送横向头像组合图，图片后接一段文本展示“今天生日的干员有...”并包含外文代号。
- `本周生日干员` / `本周干员`：发送本周生日干员图片，同日横向排列，不同日期纵向排列，今天的日期标题会高亮。
- 支持自然短句查询：`明天生日干员`、`后日干员`、`昨天干员`、`6.17干员`、`6月17日生日干员`、`上周干员`、`上上周生日干员`、`下周干员`、`本月干员`、`上月生日干员`、`下月干员`。
- 查询范围内没有生日干员时只返回文本，不渲染空图片。
- `刷新干员生日缓存`：刷新今日和本周生日缓存。

数据来源：[ark-info](https://www.npmjs.com/package/ark-info)。

默认每日生日推送时间为 00:00。

`随机干员` 支持非 @ 直接输入，随机抽取一名干员并发送方形头像，文本仅显示中文名、星级、职业、势力、种族和生日，去掉字段前缀并用 ` | ` 分隔。头像获取失败时仍发送文本。参数用空格分隔，例如 `随机干员 谢拉格`、`随机干员 岁`、`随机干员 5星`、`随机干员 两星`、`随机干员 菲林`、`随机干员 本月`、`随机干员 下月`。势力匹配国家、组织或队伍；没有匹配项时从全体干员抽取。

`随机干员陪我聊天` 等无空格聊天句不触发。每名用户在所有群聊共享滚动 5 分钟最多 10 次的额度，额度只保存在内存，重启后重置。

支持空格分隔的复合标签，按交集筛选，例如 `随机干员 辅助 3星`、`随机干员 罗德岛 菲林 五星`。职业和子职业也可筛选：`随机干员 本源术师` 或 `随机干员 术士-本源术士`（兼容术士/术师写法）。未知标签忽略；已识别标签无共同候选时，先显示 `（辅助-3星 无符合条件干员）`，再从全体随机抽取。

`随机干员标签 职业`、`随机干员标签 子职业`、`随机干员标签 势力`、`随机干员标签 种族` 返回去重的可用标签列表，以 `、` 分隔；子职业显示为 `职业-子职业`，最多展示 50 项，多余部分提示省略。标签查询不消耗抽取额度。
